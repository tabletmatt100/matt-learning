Transient Global Attention (TGlobal): How LongT5 Scales Without Side-Inputs

TL;DR

  • Why full and local attention both fall short: Standard full self-attention costs $O(\ell^2)$ pairs and runs out of memory on long documents. Sliding-window local attention cuts cost to $O(\ell r)$, but a token at the end of a $12{,}000$-token document needs dozens of layers to see the opening paragraph.
  • Core TGlobal mechanism (LongT5, Guo et al. 2022): Divide the $\ell$ input tokens into fixed blocks of $k$ tokens ($k=16$ in LongT5). Inside each encoder layer, sum and LayerNorm each block into a transient global token $g_m$, let every token attend to its local window ($2r+1$ tokens) plus all $\ell/k$ global tokens, and discard the global tokens when the layer finishes.
  • Why "transient" matters: Earlier global-local models like ETC required hand-engineered persistent global side-inputs. Synthesizing and discarding $g_m$ on the fly makes TGlobal a drop-in replacement for T5 checkpoints while adding only $\sim 10\text{k}$–$50\text{k}$ parameters (block relative position biases + LayerNorm).
  • Where it breaks: The global term $\ell \cdot (\ell / k) = \ell^2 / k$ is still quadratic—just $k=16\times$ smaller—and averaging $k$ tokens into one vector blurs exact single-token details located outside the local radius $r$.

2. How TGlobal synthesizes and discards global tokens

Earlier long-context transformers like ETC and BigBird added a permanent global memory array alongside the input sequence, where tokens attended to local neighbors and swapped messages through persistent global tokens. That works, but you have to custom-design which tokens are global for every task, and you cannot load standard T5 weights without changing the input pipeline.

Transient Global Attention (TGlobal) removes side-inputs completely. Inside each encoder self-attention layer, it performs three steps:

  1. Block Sum & Normalize: Slice the $\ell$ input embeddings $x_1, \dots, x_\ell$ into $M = \ell / k$ non-overlapping blocks of size $k$ ($k=16$). Sum the $k$ token vectors in block $m$ and apply T5's root-mean-square LayerNorm to create transient global token $g_m$.
  2. Hybrid Local + Global Keys/Values: Each input token $x_i$ acts as a query attending to at most $2r+1$ local token keys ($x_{i-r \dots i+r}$) and all $M = \ell/k$ transient global keys ($g_1, \dots, g_M$), using a dedicated block-distance relative position bias $b_{\text{global}}(m(i) - m')$.
  3. Discard After Attention: Once the weighted values are summed into $x_i$'s updated representation, $g_1, \dots, g_M$ are thrown away and rebuilt fresh in the next layer.

Worked mental-math trace of transient block pooling ($k = 4$ tokens, clean-root dimension):

Take Block $m = 1$ containing $k = 4$ tokens with distinct scalar embeddings so you can trace every token's contribution:
$$x_1 = 1, \qquad x_2 = 2, \qquad x_3 = 4, \qquad x_4 = 5$$ 1. Block sum ($s_1$): Add the $k = 4$ tokens in the block: $s_1 = 1 + 2 + 4 + 5 = \mathbf{12}$ (whose block mean is $12 / 4 = 3$).

$$g_m = \text{LayerNorm}\!\left(\sum_{j=1}^{k} x_{(m-1)k + j}\right), \qquad \text{Keys}(x_i) = \underbrace{\{x_j : |i - j| \le r\}}_{\text{Local window } (\le 2r+1)} \;\cup\; \underbrace{\{g_1, g_2, \dots, g_{\ell/k}\}}_{\text{Transient globals } (\ell/k)}$$
Because $g_m$ lives in the exact same embedding space $\mathbb{R}^{d_{\text{model}}}$ as $x_i$, TGlobal reuses the standard T5 key and value projection matrices $W_K, W_V$ on $g_m$ with zero extra projection weights.

3. Complexity math & PEGASUS principle-sentence pre-training

How many attention pairs does TGlobal actually compute? In Figure 2b of the LongT5 paper, the attention matrix consists of two pieces for all $\ell$ queries:

  • Left banded matrix (Local): Each of the $\ell$ tokens attends to its local window of width $W$ (proportional to $r$), costing $\ell \cdot W \sim O(\ell r)$ pairs.
  • Right rectangle (Transient Global): Each of the $\ell$ tokens also attends to all $\ell / k$ global tokens, adding $\ell \cdot (\ell / k) = \ell^2 / k$ pairs.
$$\text{Pairs}_{\text{Full}} = \ell^2, \qquad \text{Pairs}_{\text{Local}} = \ell \cdot W \;\sim\; O(\ell r), \qquad \text{Pairs}_{\text{TGlobal}} = \ell\!\left(W + \frac{\ell}{k}\right) \;\sim\; O\!\left(\ell\!\left(r + \frac{\ell}{k}\right)\right)$$
Notice that TGlobal is technically $O(\ell r + \ell^2/k)$: at $k=16$, the quadratic global rectangle is $16\times$ smaller than full attention, letting LongT5-base scale to $12\text{k}$–$16\text{k}$ tokens before hitting the TPU memory ceiling that kills full T5-base at $6\text{k}$.

Worked mental-math trace of attention pair savings ($\ell = 16$, local window $W = 3$, block size $k = 4$):

Compare the total query-key pairs computed in one layer for a toy sequence of $\ell = 16$ tokens:
1. Full self-attention ($\ell^2$): Every token attends to all $16$ tokens $\implies 16 \times 16 = \mathbf{256\text{ pairs}}$.
2. Local attention ($\ell \times W$ with $W = 3$): Each of the $16$ tokens attends to $W = 3$ local tokens $\implies 16 \times 3 = \mathbf{48\text{ pairs}}$ (fast, but blind past distance $1$).
3. TGlobal attention ($\ell \times (W + \ell/k)$ with $k = 4$): There are $\ell / k = 16 / 4 = \mathbf{4\text{ global tokens}}$, so each of the $16$ queries attends to $3\text{ local} + 4\text{ global} = 7\text{ keys}$:

LongT5 pairs TGlobal with PEGASUS Principle Sentences Generation (PSG) during pre-training: instead of masking random short spans (T5 span corruption), it scores every sentence $x_i$ in a document by its ROUGE-F1 overlap with the rest of the document $D \setminus \{x_i\}$, masks the top $20\%$ most central sentences, and trains the decoder to generate them all together as a pseudo-summary. That forces the encoder's transient global tokens $g_m$ to route document-level themes across thousands of tokens.
