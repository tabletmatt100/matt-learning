Calculus for ML Refresher: The 10% of Calc 1–3 You Actually Need

TL;DR

  • Forget integration tricks and vector-field theorems: You don't need trig substitutions, integration by parts, spherical triple integrals, or Stokes' theorem for ML. Deep learning is 99% differential calculus (derivatives).
  • A gradient ($\nabla_w L$) is just a list of Calc 1 derivatives: Each partial derivative $\frac{\partial L}{\partial w_i}$ freezes all other weights and asks: "If I nudge $w_i$ up by $\epsilon$, how much does the loss $L$ change?" Stacking them into a vector points steepest uphill, so we step in $-\nabla_w L$.
  • Backpropagation is just the Chain Rule: In a chain $w \to z \to \hat{y} \to L$, you multiply local derivatives backward ($\frac{\partial L}{\partial w} = \frac{\partial L}{\partial \hat{y}} \frac{\partial \hat{y}}{\partial z} \frac{\partial z}{\partial w}$). When one variable feeds multiple paths, you add the derivatives from each branch.
  • Second derivatives (Hessian) measure bowl curvature: The first derivative tells you which way is downhill; the second derivative tells you how sharply the slope bends, setting the maximum safe learning rate before steps overshoot and explode.

1. Partials & The Gradient: Which Way Is Downhill?

In Calc 1, the derivative $f'(w)$ is the slope of a curve: if $f'(w) = -4$, nudging $w$ by $+0.01$ changes $f(w)$ by roughly $(-4)(0.01) = -0.04$.

In Calc 3, a neural network loss $L(w_1, w_2, \dots, w_d)$ depends on millions of weights. To take a partial derivative $\frac{\partial L}{\partial w_1}$, you treat every other weight ($w_2, w_3, \dots$) as a frozen number and take the ordinary Calc 1 derivative with respect to $w_1$. Packing all $d$ partial derivatives into a column vector gives the gradient:

$$\nabla_w L = \begin{bmatrix} \frac{\partial L}{\partial w_1} \\ \frac{\partial L}{\partial w_2} \end{bmatrix}, \qquad w_{\text{new}} = w - \eta \nabla_w L$$
Why does $\nabla_w L$ point steepest uphill? For any unit step direction $u$, the rate of change (directional derivative) is $\nabla_w L \cdot u = \|\nabla_w L\|_2 \cos\theta$, which is maximized when $\theta = 0^\circ$ ($u$ points along $\nabla_w L$) and most negative when $\theta = 180^\circ$ ($u$ points along $-\nabla_w L$).

Worked 2-weight mental-math example:

Suppose our loss bowl is $L(w_1, w_2) = w_1^2 + 3w_2^2$ and our current weights are $(w_1, w_2) = (2, -1)$ with learning rate $\eta = 0.1$:

1. Current loss: $L(2, -1) = (2)^2 + 3(-1)^2 = 4 + 3 = \mathbf{7}$.
2. Partial derivatives: $\frac{\partial L}{\partial w_1} = 2w_1 = 2(2) = \mathbf{4}$, and $\frac{\partial L}{\partial w_2} = 6w_2 = 6(-1) = \mathbf{-6}$. So $\nabla_w L = [4, -6]^\top$.
3. Gradient descent step: $w_{\text{new}} = [2, -1]^\top - 0.1\,[4, -6]^\top = [\mathbf{1.6}, \mathbf{-0.4}]^\top$.
4. New loss: $L(1.6, -0.4) = (1.6)^2 + 3(-0.4)^2 = 2.56 + 0.48 = \mathbf{3.04}$ (dropped from $7$ to $3.04$ in one step).

2. The Chain Rule Is Backpropagation

A neural network is just nested functions: inputs multiply weights to make pre-activations $z$, which pass through an activation function to make predictions $\hat{y}$, which enter a loss function $L$. The Chain Rule says the derivative of a chain is the product of the local derivatives along the path:

$$w \longrightarrow z = wx + b \longrightarrow \hat{y} = f(z) \longrightarrow L(\hat{y}, y) \quad \Longrightarrow \quad \frac{\partial L}{\partial w} = \underbrace{\frac{\partial L}{\partial \hat{y}}}_{\text{loss slope}} \cdot \underbrace{\frac{\partial \hat{y}}{\partial z}}_{\text{activation slope}} \cdot \underbrace{\frac{\partial z}{\partial w}}_{=\, x}$$
Multivariable rule: Multiply local derivatives along a single serial path; add paths together wherever a variable branches into multiple downstream consumers.

3. The Only 4 Derivatives You Need to Know by Heart

PyTorch's autograd computes derivatives for you, but knowing four specific derivatives explains why modern architectures use ReLU and Cross-Entropy:

Function $f(z)$Derivative $f'(z)$Key ML Consequence
Quadratic: $\frac{1}{2}w^2$ $w$ Slope shrinks linearly as you approach $w=0$ ($L_2$ weight decay & MSE loss).
ReLU: $\max(0, z)$ $\begin{cases} 1 & z > 0 \\ 0 & z < 0 \end{cases}$ When active ($z>0$), multiplying by $1$ passes gradients backward through 100 layers without shrinking!When $z<0$, gradient is $0$ ("dead ReLU").
Sigmoid: $\sigma(z) = \frac{1}{1+e^{-z}}$ $\sigma(z)(1 - \sigma(z))$ Maximum derivative is only $\mathbf{0.25}$ (at $z=0$). Multiply $0.25$ across 10 layers and gradient shrinks by $0.25^{10} \approx 10^{-6}$ (vanishing gradient).
Log & Exp: $\ln(p)$, $e^z$ $\frac{1}{p}$, $\;e^z$ Pairing $-\ln(\hat{p})$ (cross-entropy) with sigmoid/softmax cancels the $\sigma(z)(1-\sigma(z))$ term completely!
3-Line Proof: Why Cross-Entropy + Sigmoid cancels to $\frac{\partial L}{\partial z} = \hat{p} - y$

If you use MSE loss with a sigmoid output $\hat{p} = \sigma(z)$ when $z = -5$ ($\hat{p} \approx 0.0067$) and true label $y = 1$, the sigmoid derivative $\hat{p}(1-\hat{p}) \approx 0.0066$ stalls learning even though the model is terribly wrong.

With binary cross-entropy $L = -\left[y \ln \hat{p} + (1-y)\ln(1-\hat{p})\right]$, watch the chain rule cancel $\hat{p}(1-\hat{p})$:

$$\frac{\partial L}{\partial \hat{p}} = -\frac{y}{\hat{p}} + \frac{1-y}{1-\hat{p}} = \frac{\hat{p} - y}{\hat{p}(1 - \hat{p})} \quad \Longrightarrow \quad \frac{\partial L}{\partial z} = \frac{\partial L}{\partial \hat{p}} \cdot \frac{\partial \hat{p}}{\partial z} = \frac{\hat{p} - y}{\cancel{\hat{p}(1 - \hat{p})}} \cdot \cancel{\hat{p}(1 - \hat{p})} = \mathbf{\hat{p} - y}$$

That exact cancellation ($\text{gradient} = \text{prediction} - \text{truth}$) also holds for multiclass Softmax + Cross-Entropy, giving strong, clean gradients whenever a prediction is wrong.

4. Second Derivatives, Taylor Series & Why Learning Rates Explode

If the first derivative $L'(w)$ is velocity (slope), the second derivative $L''(w)$ (or the Hessian matrix $H$ in high dimensions) is curvature—how fast the slope itself changes as you move.

Using a second-order Taylor approximation around current weight $w$ with gradient $g = L'(w)$ and curvature $h = L''(w) > 0$:

$$L(w - \eta g) \approx L(w) - \eta g^2 + \frac{1}{2} h \eta^2 g^2 = L(w) - \eta g^2 \left(1 - \frac{1}{2} h \eta\right)$$
Look at the factor $\left(1 - \frac{1}{2} h \eta\right)$: best 1-step drop happens at $\eta^* = \frac{1}{h}$ (Newton's step). If $\eta > \frac{2}{h}$, that factor turns negative and the loss increases on every step!
