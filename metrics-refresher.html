Classification Metrics Refresher: From Type I/II Errors to ROC-AUC and PR-AUC

Almost every classification metric in machine learning and statistics—Precision, Recall, Sensitivity, Specificity, Type I / Type II errors, $F_1$, ROC-AUC, and PR-AUC—is built from the exact same four numbers inside a $2 \times 2$ confusion matrix.

Why do different fields have three different names for the exact same fraction? Because medicine (Sensitivity / Specificity), hypothesis testing (Type I / Type II errors), and information retrieval (Precision / Recall) each invented their own vocabulary. Once you see which row or column of the $2 \times 2$ table is sitting in the denominator, you never have to memorize the formulas as isolated facts again.

1. The $2 \times 2$ Confusion Matrix: Row Ratios vs. Column Ratios

Every binary classifier makes two kinds of right calls—catching a real positive (True Positive, $TP$) and clearing a real negative (True Negative, $TN$)—and two kinds of mistakes. A Type I error (False Positive, $FP$) is a false alarm on a real negative (like the boy who cried wolf the first time, when there was no wolf). A Type II error (False Negative, $FN$) is a missed real positive (the second time, when a real wolf attacked and nobody believed it).

Worked Example (Tracing every ratio on 110 screened patients: 10 sick, 100 healthy):

Suppose a diagnostic test catches $TP = 8$ of the $10$ sick patients (missing $FN = 2$), and triggers $FP = 16$ false alarms among the $100$ healthy patients (clearing $TN = 84$):
1. Conditioned on Actual Positives (Top Row $= TP + FN = 10$):
Recall $=$ Sensitivity $=$ $\text{TPR}$ $= \frac{TP}{TP + FN} = \frac{8}{10} = \mathbf{80\%}$ (and miss rate $\text{FNR} = \frac{2}{10} = 20\%$; notice $\text{TPR} + \text{FNR} = 100\%$).
2. Conditioned on Actual Negatives (Bottom Row $= FP + TN = 100$):
Specificity ($\text{TNR}$) $= \frac{TN}{FP + TN} = \frac{84}{100} = \mathbf{84\%}$, and False Positive Rate ($\text{FPR}$) $= \frac{FP}{FP + TN} = \frac{16}{100} = \mathbf{16\%}$ (notice $\text{TNR} + \text{FPR} = 100\%$).
3. Conditioned on Flagged Alarms (Left Column $= TP + FP = 8 + 16 = 24$):
Precision ($\text{PPV}$) $= \frac{TP}{TP + FP} = \frac{8}{8 + 16} = \frac{8}{24} = \mathbf{33.3\%}$! Even with $80\%$ sensitivity and $84\%$ specificity, only $1$ in $3$ positive test results is actually sick because healthy people outnumber sick people $10\text{ to }1$.

When you want a single number that requires both Precision and Recall to be high at a chosen threshold, use their harmonic mean, the $F_1$ Score: $F_1 = \frac{2 \cdot \text{Precision} \cdot \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2\,TP}{2\,TP + FP + FN}$. Unlike a simple average, the harmonic mean punishes extreme imbalance: if a lazy model flags everyone ($\text{Recall} = 100\%$, $\text{Precision} = 2\%$), its $F_1$ drops near $4\%$ instead of $51\%$.

Which pair of rates shares the exact same denominator (all Actual Negatives, $FP + TN$) and always adds up to $100\%$?

2. Threshold-Free Curves: ROC-AUC vs. PR-AUC

Precision, Recall, and Specificity only grade a classifier at one single cutoff $t$. If you lower $t$, you catch more positives ($\text{Recall} \uparrow$) at the cost of more false alarms ($\text{FPR} \uparrow$, $\text{Precision} \downarrow$). To evaluate a model's ranking quality across every possible cutoff at once, we sweep $t$ from $1$ down to $0$ and plot two curves:

$$\text{ROC Curve: } \underbrace{\text{TPR}}_{\frac{TP}{TP+FN}} \text{ vs. } \underbrace{\text{FPR}}_{\frac{FP}{FP+TN}}, \qquad \text{PR Curve: } \underbrace{\text{Precision}}_{\frac{TP}{TP+FP}} \text{ vs. } \underbrace{\text{Recall}}_{\frac{TP}{TP+FN}}$$

Look at the two denominators in those equations to see how they react when you multiply the number of negative examples in your dataset by $10\times$ (say, from $100$ healthy patients to $1{,}000$ healthy patients, so both $FP$ and $TN$ scale up $10\times$). Because $\text{TPR}$ uses only the positive row and $\text{FPR} = \frac{10\,FP}{10(FP + TN)}$ normalizes the negative row by its own total, the ROC curve and ROC-AUC do not change at all when class balance changes! By contrast, Precision $= \frac{TP}{TP + 10\,FP}$ pits $TP$ directly against $10\,FP$, so PR-AUC drops sharply whenever negatives flood the alert queue.

In our clinic example ($TP = 8, FN = 2$ out of $10$ sick; $FP = 16, TN = 84$ out of $100$ healthy), suppose $10\times$ as many healthy people visit the clinic ($1{,}000$ healthy people at the same $16\%$ false-alarm rate, so $FP = 160$ and $TN = 840$). 3. Comparing Classification Metrics at a Glance

Metric Formula Denominator (Conditioned On) When to Prioritize
Recall / Sensitivity (TPR) $\frac{TP}{TP + FN}$ All Real Positives ($1 - \text{FNR}$) High Type II ($FN$) miss cost: cancer screening, safety hazards, fraud catch rate
Specificity (TNR) $\frac{TN}{TN + FP}$ All Real Negatives ($1 - \text{FPR}$) Diagnostic rule-in tests where healthy patients must be cleared reliably
Precision (PPV) $\frac{TP}{TP + FP}$ All Flagged Alerts (ignores $TN$) High Type I ($FP$) false-alarm cost: spam filter blocking real email, expensive human review queue
$F_1$ Score $\frac{2\,P \cdot R}{P + R}$ Harmonic mean of Precision & Recall Single-threshold summary when both false alarms and missed positives hurt
ROC-AUC vs. PR-AUC Area under curve across all $t$ ROC: class-invariant ($0.50$ baseline)
PR: alert-focused ($\pi$ baseline)		 Use ROC-AUC for balanced ranking; use PR-AUC whenever positives are rare ($\pi \ll 50\%$)
