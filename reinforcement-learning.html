Reinforcement Learning: From Delayed Rewards to TD Updates

TL;DR

  • Problem: Unlike supervised learning, an agent receives no label for the best action; it only gets sparse, delayed scalar rewards from an environment.
  • Core mechanism: The agent estimates expected discounted return $G_t$ using the Bellman equation and updates value estimates online via TD error $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$.
  • Where it breaks: Poorly shaped rewards cause reward hacking, and aggressive discounting ($\gamma$ too low) makes the agent ignore large future payoffs.

2. Returns and how values propagate backward

An RL agent maximizes the discounted return $G_t$, not the raw sum of future rewards. Discounting keeps infinite-horizon sums finite and encodes urgency: every extra step multiplies future reward by $\gamma$.

Concrete trace: Suppose an episode produces rewards $R_1 = 0$, $R_2 = 0$, $R_3 = 10$ with $\gamma = 0.9$.

$G_2 = R_3 = 10.00$
$G_1 = R_2 + 0.9\,G_2 = 0 + 0.9(10.00) = 9.00$
$G_0 = R_1 + 0.9\,G_1 = 0 + 0.9(9.00) = 8.10$

$$G_t = \sum_{k=0}^{\infty} \gamma^k R_{t+k+1} = R_{t+1} + \gamma G_{t+1}$$

Waiting until the end of a long episode to compute $G_t$ is slow. Instead, Temporal-Difference (TD) learning uses bootstrapping: it updates $V(S_t)$ immediately after one step using $R_{t+1} + \gamma V(S_{t+1})$. Step through three episodes on a 4-state corridor [S0]→[S1]→[S2]→[Goal +10] ($\gamma = 0.9, \alpha = 0.5$) to watch values march backward.

3. Faded TD practice and closed-book recall

The Bellman TD(0) update rule is $V(S_t) \leftarrow V(S_t) + \alpha \big[R_{t+1} + \gamma V(S_{t+1}) - V(S_t)\big]$. Trace the full worked example, then finish Step 3 of the second one yourself.

Example 1 (full): $V(S_1) = 2.0$, transition $S_1 \to S_2$ gives $R = 0$, $V(S_2) = 9.0$, with $\gamma = 0.9, \alpha = 0.5$.

1. Target: $0 + 0.9 \times 9.0 = 8.10$.
2. TD error: $\delta = 8.10 - 2.0 = +6.10$.
3. Update: $V_{\text{new}}(S_1) = 2.0 + 0.5(6.10) = 5.05$.

Stage 4: Closed-Book Retrieval (Blank-Sheet Test)

Explain Bootstrapping Without Looking Up

In one or two sentences, why does TD learning update $V(S_t)$ using $R_{t+1} + \gamma V(S_{t+1})$ instead of waiting for the full return $G_t$?

Canonical answer: TD bootstraps off its own estimate $V(S_{t+1})$ so it can update immediately after every single step—even in infinite or very long episodes—trading a small initial bias for much lower variance than Monte Carlo.
