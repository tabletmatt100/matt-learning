How Attention Works: From First Principles to Multi-Head Math

Read the sentence: "The trophy didn't fit into the suitcase because it was too big." When you hit the word "it", your brain immediately reaches back and links "it" to "trophy" (whereas if the last word were "small", "it" would flip to "suitcase").

Before Transformers, sequence models like Recurrent Neural Networks (RNNs) and LSTMs read words strictly one by one from left to right, squashing everything seen so far into a single fixed-size hidden vector $h_t$. By the time an RNN reached word $50$, signal from word $1$ had been multiplied by $49$ weight matrices in a row—blurring early details, causing vanishing gradients, and preventing GPUs from training across all tokens in parallel.

Self-Attention (Vaswani et al., 2017) throws away the sequential bottleneck completely: it lets every token look directly at every other token in a single parallel matrix multiply, acting like a differentiable, soft dictionary lookup.

1. Soft Dictionary Lookup: Queries ($Q$), Keys ($K$), Values ($V$) & $\sqrt{d_k}$

Think of how you search a database or dictionary: you type a Query, the database compares your Query against every item's Key, and it returns the matching item's Value.

In Scaled Dot-Product Attention, every input token vector $x_i \in \mathbb{R}^{d_{\text{model}}}$ is multiplied by three learned projection matrices ($W_Q, W_K, W_V$) to produce three distinct vectors of width $d_k$:

The Query ($q_i$) represents what token $i$ is looking for; the Key ($k_j$) advertises what token $j$ contains; and the Value ($v_j$) holds the payload information token $j$ passes along when selected. Instead of a hard $100\% / 0\%$ match, attention takes the dot product $q_i \cdot k_j$ against every Key, divides by $\sqrt{d_k}$, applies softmax so the weights sum to $1$, and blends the Values:

$$\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{Q K^\top}{\sqrt{d_k}}\right) V$$

Why divide by $\sqrt{d_k}$ before softmax? If the coordinates of $q_i$ and $k_j$ are independent random variables with mean $0$ and variance $1$, their dot product $q_i \cdot k_j = \sum_{m=1}^{d_k} q_{im} k_{jm}$ is a sum of $d_k$ unit-variance terms—so its variance grows to $d_k$ and its standard deviation grows to $\sqrt{d_k}$! At $d_k = 64$, raw dot products swing as wide as $\pm 16$, pushing softmax into flat saturation where one token gets $0.999999$ and all gradients vanish. Dividing by $\sqrt{d_k}$ rescales the dot-product variance right back to $1$.

Worked Example (Tracing 2-token attention by hand with clean root $d_k = 4 \implies \sqrt{d_k} = 2$):

Suppose Token 1 has Query $q_1 = [2, 0, 2, 0]$, and the two tokens have Keys $k_1 = [1, 0, 1, 0]$, $k_2 = [2, 0, 2, 0]$ and scalar Values $v_1 = 10$, $v_2 = 30$:
1. Raw dot products ($q_1 \cdot k_j$): $q_1 \cdot k_1 = 2(1) + 2(1) = \mathbf{4}$, and $q_1 \cdot k_2 = 2(2) + 2(2) = \mathbf{8}$.
2. Scale by $\sqrt{d_k} = \sqrt{4} = 2$: Scaled scores are $[4/2,\; 8/2] = [\mathbf{2},\; \mathbf{4}]$.
3. Weighted Value sum: Suppose after softmax (or on a clean $1/4$ vs. $3/4$ weight split $\alpha = [\frac{1}{4},\; \frac{3}{4}]$), Token 1 blends the Values as $\alpha_1 v_1 + \alpha_2 v_2 = \frac{1}{4}(10) + \frac{3}{4}(30) = 2.5 + 22.5 = \mathbf{25}$.

If query $q$ and key $k$ have dimension $d_k = 64$ with independent unit-variance entries, what is the standard deviation of the raw dot product $q \cdot k$, and what breaks if you omit the $\frac{1}{\sqrt{d_k}}$ divisor?

2. Multi-Head Attention (MHA) & Causal Decoder Masking

A single attention head only gets one softmax distribution per token—so if a word needs to attend to its grammatical subject and its modifying adjective and the previous punctuation mark at the same time, one head has to average all three together.

Multi-Head Attention (MHA) solves this by splitting the model width $d_{\text{model}}$ into $h$ parallel heads, each of width $d_k = d_{\text{model}} / h$ (for example, $d_{\text{model}} = 512$ split into $h = 8$ heads of width $d_k = 64$). Each head runs its own $(W_Q^{(i)}, W_K^{(i)}, W_V^{(i)})$ lookup in its own 64D subspace, and their $h$ outputs are concatenated back to width $512$ and mixed by an output matrix $W_O$:

$$\text{MHA}(X) = \text{Concat}\bigl(\text{head}_1, \dots, \text{head}_h\bigr) W_O, \qquad M_{ij} = \begin{cases} 0 & j \le i \\ -\infty & j > i \end{cases}$$

Notice that splitting $d_{\text{model}} = 512$ into $8$ heads of width $64$ costs the exact same total FLOPs and parameters as a single giant head of width $512$, while giving the layer $8$ independent attention maps!

Finally, in an autoregressive decoder like GPT that predicts one word at a time from left to right, Token $i$ cannot be allowed to peek at future Token $j > i$ during parallel training. A causal mask $M$ adds $-\infty$ to every upper-triangle logit ($j > i$) before softmax runs. Because $e^{-\infty} = 0$, future tokens receive exact $0$ attention weight while the remaining past and present weights ($j \le i$) still normalize cleanly to sum to $1$.

A Transformer has model dimension $d_{\text{model}} = 768$ and uses $h = 12$ attention heads for a sequence of $T = 10$ tokens. What is the shape of a single head's Query matrix $Q^{(i)}$, and what is the shape of that head's attention weight matrix $A^{(i)} = \text{softmax}(Q^{(i)} K^{(i)\top} / \sqrt{d_k})$?

In a causal GPT decoder, why do we set future attention scores ($j > i$) to $-\infty$ before softmax instead of setting them to $0$ before softmax (or zeroing them out after softmax)?

3. Comparing Sequence & Attention Variants

Mechanism Path Length (Token $1 \to T$) Parallel Training? When to Use / Tradeoff
Recurrent (RNN / LSTM) $O(T)$ sequential hops No (step $t$ waits for $t-1$) Tiny $O(1)$ per-step inference state, but slow to train and forgets long context
Bidirectional Self-Attention $O(1)$ ($1$ direct hop) Yes (full $T \times T$ matrix) Encoders (BERT, ViT) reading full inputs for classification or embeddings
Causal Masked Self-Attention $O(1)$ (from any $j \le i$) Yes (lower-triangular mask) Autoregressive decoders (GPT, Llama, Claude) generating one token at a time
Cross-Attention $O(1)$ (decoder $\to$ encoder) Yes ($T_{\text{dec}} \times T_{\text{enc}}$) Encoder-decoder models (T5, Whisper) where queries $Q$ come from the decoder and $K, V$ come from the encoder
