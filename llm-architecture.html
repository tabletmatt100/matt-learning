Inside the Transformer Block: Embeddings, Residual Stream, FFN & Unembedding

When people first learn how a Large Language Model (LLM) works, self-attention gets almost all the spotlight. Here is a surprise: inside a standard Transformer block, self-attention only accounts for about one-third of the weights. The other two-thirds live inside the Feed-Forward Network (FFN / MLP) sitting right after attention.

Even more striking is the strict division of labor inside the block. Self-attention is the only place in the entire network where tokens exchange information across different sequence positions. Every other component—the input embedding lookup ($W_E$), LayerNorm / RMSNorm, the FFN, and the final unembedding projection ($W_U$)—operates independently on one single token vector at a time.

Following a single token from its integer ID at the bottom of the network, up the shared residual stream conveyor belt, through the FFN memory bank, and out the unembedding matrix to next-token logits demystifies how all the pieces of a Transformer fit together.

1. Entering the Residual Stream: Embeddings ($W_E$) & Pre-Norm (RMSNorm)

Before Layer 1 starts, a tokenizer chops text like "Paris is in" into integer vocabulary IDs, say $[402, 19, 12]$. Because raw ID numbers have no geometric meaning, each token ID $k$ looks up row $k$ of the learned Embedding Matrix $W_E \in \mathbb{R}^{V \times d_{\text{model}}}$ (where $V$ is vocabulary size and $d_{\text{model}}$ is the hidden vector width).

Once that initial vector $x^{(0)} \in \mathbb{R}^{d_{\text{model}}}$ is sliced out of $W_E$, it rides on the Residual Stream—a shared vector wire of constant width $d_{\text{model}}$ that runs straight from the bottom of Layer 1 to the top of the final layer. Neither Attention nor the FFN ever overwrites the residual stream; instead, each sublayer reads a normalized copy of $x$ via Pre-Norm (RMSNorm) and adds its update delta back onto the stream:

$$x_{\text{mid}} = x + \text{Attention}\bigl(\text{RMSNorm}_1(x)\bigr), \qquad x_{\text{out}} = x_{\text{mid}} + \text{FFN}\bigl(\text{RMSNorm}_2(x_{\text{mid}})\bigr)$$

Why normalize before each sublayer? Adding deltas across 32 to 80 layers causes vector magnitudes to explode unless you rescale them. RMSNorm divides $x$ by the square root of its average squared coordinate:
1. Square each coordinate: $[1^2,\; 1^2,\; 3^2,\; 5^2] = [1,\; 1,\; 9,\; 25]$.
2. Mean square ($\text{MS}$) & root ($\text{RMS}$): $\text{MS} = \frac{1 + 1 + 9 + 25}{4} = \frac{36}{4} = \mathbf{9} \implies \text{RMS}(x) = \sqrt{9} = \mathbf{3}$.
3. Divide by $\text{RMS}(x) = 3$: $\text{RMSNorm}(x) = \mathbf{[\frac{1}{3},\; \frac{1}{3},\; 1,\; \frac{5}{3}]}$ (multiplied elementwise by learned gain $\gamma$).

Why do modern LLMs (Llama, Mistral, Gemini) place RMSNorm on the branch entering Attention and FFN ($x + \text{Sublayer}(\text{Norm}(x))$) instead of putting LayerNorm directly on the main residual stream ($ \text{Norm}(x + \text{Sublayer}(x))$)?

2. The FFN (2/3 of the Weights) & Leaving via Unembedding ($W_U$)

After self-attention gathers context from earlier words into the token's vector $x_{\text{mid}}$, what does the Feed-Forward Network (FFN) do? Think of Attention as routing information between tokens, and the FFN as computing on and enriching each token's representation using a massive bank of learned factual and syntactic detectors.

In a classic FFN, an up-projection matrix $W_{\text{up}} \in \mathbb{R}^{d_{\text{model}} \times d_{\text{ff}}}$ expands the token vector to a $4\times$ wider intermediate dimension ($d_{\text{ff}} = 4\,d_{\text{model}}$), passes it through a non-linear activation (GELU or SwiGLU), and projects it back down to width $d_{\text{model}}$ via $W_{\text{down}} \in \mathbb{R}^{d_{\text{ff}} \times d_{\text{model}}}$:

$$\text{FFN}(u) = \text{GELU}\bigl(u W_{\text{up}}\bigr) W_{\text{down}}, \qquad z = x_{\text{final}} W_U \in \mathbb{R}^{1 \times V}, \qquad P(\text{next token}) = \text{softmax}(z)$$

Count the matrix sizes in a block of width $d$: Attention has four $d \times d$ matrices ($W_Q, W_K, W_V, W_O = 4d^2$ parameters), while the FFN has two $d \times 4d$ matrices ($W_{\text{up}}, W_{\text{down}} = 8d^2$ parameters). That $8d^2$ vs. $4d^2$ ratio is why two-thirds of a Transformer block's parameters live in the FFN!

Finally, after the token vector exits the last layer as $x_{\text{final}} \in \mathbb{R}^{1 \times d_{\text{model}}}$, we multiply it by the Unembedding Matrix $W_U \in \mathbb{R}^{d_{\text{model}} \times V}$. Column $j$ of $W_U$ is the output vector for vocabulary word $j$, so the dot product $z_j = x_{\text{final}} \cdot W_U[:, j]$ is word $j$'s raw logit score before softmax turns the $V$ logits into next-token probabilities.

A Transformer layer has model dimension $d_{\text{model}} = 1{,}000$ ($d^2 = 1\text{M}$) and FFN intermediate width $d_{\text{ff}} = 4{,}000$. Multi-head attention uses 4 projections ($W_Q, W_K, W_V, W_O$, each $1{,}000 \times 1{,}000$), and the FFN uses $W_{\text{up}}$ ($1{,}000 \times 4{,}000$) and $W_{\text{down}}$ ($4{,}000 \times 1{,}000$). How many weights are in Attention vs. the FFN?

A tiny LLM has $d_{\text{model}} = 2$ and final residual vector $x_{\text{final}} = [3,\; 1]$. In the unembedding matrix $W_U$, the column for word "France" is $[4,\; 2]^\top$ and the column for word "Spain" is $[2,\; 5]^\top$. Which word gets the higher raw logit $z_j = x_{\text{final}} \cdot W_U[:, j]$?

3. Comparing Every Component of a Transformer LLM

Component Tensor Shape Mixes Across Tokens? Functional Job
Token Embedding ($W_E$) $V \times d_{\text{model}}$ No (per-token row lookup) Converts discrete token ID $k$ into initial residual vector $x^{(0)}$
Pre-Norm (RMSNorm) $d_{\text{model}}$ scale vector $\gamma$ No (per-token vector norm) Stabilizes activation magnitudes entering Attention and FFN
Multi-Head Attention $4 \times (d_{\text{model}} \times d_{\text{model}})$ ($\sim \frac{1}{3}$ params) Yes (only place tokens talk!) Routes and blends context from earlier token positions into current $x$
Feed-Forward Network (FFN) $d_{\text{model}} \to d_{\text{ff}} \to d_{\text{model}}$ ($\sim \frac{2}{3}$ params) No (independent per token) Non-linear feature detector & factual key-value memory bank
Unembedding ($W_U$) $d_{\text{model}} \times V$ No (per-position dot products) Projects final residual vector $x_{\text{final}}$ to $V$ vocabulary logits
