Inside the Transformer Block: Embeddings, Residual Stream, FFN & Unembedding

TL;DR

  • The two-job division of labor: Self-attention is the only place where tokens talk to other tokens across sequence positions. Every other piece of an LLM—embedding, LayerNorm / RMSNorm, the Feed-Forward Network (FFN / MLP), and the unembedding matrix—operates independently on one token vector at a time.
  • The Residual Stream ($x \in \mathbb{R}^{d_{\text{model}}}$): A shared conveyor belt of constant width $d_{\text{model}}$. Neither Attention nor the FFN overwrites $x$; each reads a normalized copy of $x$, computes a delta, and adds it back: $x \leftarrow x + \text{Sublayer}(\text{Norm}(x))$.
  • The Fully Connected FFN (~$\frac{2}{3}$ of all parameters): Expands each token vector from $d_{\text{model}}$ to a wider intermediate dimension $d_{\text{ff}} \approx 4\,d_{\text{model}}$ via $W_{\text{up}}$, applies a non-linear gate (ReLU/GELU or SwiGLU), and projects back down via $W_{\text{down}}$. It acts as a learned key-value memory bank that injects factual associations into the token's vector.
  • The Unembedding Matrix ($W_U \in \mathbb{R}^{d_{\text{model}} \times V}$): Multiplies the final layer's residual vector $x_{\text{final}}$ against one column per vocabulary token to produce $V$ raw logits $z = x_{\text{final}} W_U$, which softmax turns into next-token probabilities.
SymbolPlain-English MeaningMatrix Shape
$V,\; d_{\text{model}},\; d_{\text{ff}}$ Vocabulary size, residual stream width, and FFN hidden width e.g. $V\!=\!100\text{k},\; d_{\text{model}}\!=\!4096$

1. Predict first: why isn't Self-Attention enough on its own?

In the Attention article, we saw that attention blends Value vectors across tokens: $z_i = \sum_j A_{ij} v_j$, where $V = X W_V$ and the heads are mixed by $W_O$.

Suppose you strip out the fully connected FFN layers and stack 32 layers of Self-Attention back-to-back. Furthermore, consider a standard Transformer block where $d_{\text{model}} = 1000$ and the FFN expands to $d_{\text{ff}} = 4\,d_{\text{model}} = 4000$. Attention has 4 square projection matrices ($W_Q, W_K, W_V, W_O$, each $d_{\text{model}} \times d_{\text{model}}$). The FFN has two rectangular matrices ($W_{\text{up}}$ of shape $d_{\text{model}} \times 4d_{\text{model}}$ and $W_{\text{down}}$ of shape $4d_{\text{model}} \times d_{\text{model}}$).

2. Entering the stream: Token Embedding ($W_E$), Positions & the Residual Highway

Before layer 1 even starts, raw text like "Paris is in" is split by a tokenizer into integer IDs, say $[402, 19, 12]$. An integer ID has no geometry—token $402$ is not "twice as big" as token $201$.

To enter the network, each token ID $k$ looks up row $k$ of the Embedding Matrix $W_E \in \mathbb{R}^{V \times d_{\text{model}}}$. Mathematically, multiplying a one-hot vector $e_k \in \{0,1\}^{1 \times V}$ (which has a $1$ at index $k$ and $0$ everywhere else) by $W_E$ simply slices out row $k$ with zero arithmetic:

Concrete trace ($V = 4$ tokens, $d_{\text{model}} = 3$ dimensions, distinct numbers):

Suppose our miniature vocabulary has 4 tokens—ID 0: "Paris", ID 1: "is", ID 2: "in", ID 3: "France"—and the learned embedding matrix $W_E$ ($4 \times 3$) is: $$W_E = \begin{bmatrix} 1 & 2 & 3 \\ 4 & 0 & 1 \\ 2 & 5 & 0 \\ 3 & 1 & 4 \end{bmatrix} \begin{array}{l} \leftarrow \text{row 0: ``Paris''} \\ \leftarrow \text{row 1: ``is''} \\ \leftarrow \text{row 2: ``in''} \\ \leftarrow \text{row 3: ``France''} \end{array}$$ When the current input token is ID $k = 2$ ("in"), its initial residual stream vector is simply row 2: $$x^{(0)} = e_2 W_E = [0, 0, 1, 0]\,W_E = \mathbf{[2,\; 5,\; 0]}$$ (In classic Transformers like GPT-2, a positional vector $p_{\text{pos}} \in \mathbb{R}^{d_{\text{model}}}$ is added right here: $x^{(0)} = W_E[k] + p_{\text{pos}}$; modern LLMs like Llama and Gemini instead rotate $Q$ and $K$ inside attention via RoPE.)

Once $x^{(0)} \in \mathbb{R}^{d_{\text{model}}}$ is created, it rides on the Residual Stream—a persistent vector wire of width $d_{\text{model}}$ that runs straight from the input embedding all the way to the final output. Each Transformer block has two sublayers that read from the stream via Pre-Norm (LayerNorm or RMSNorm) and add their result back into the stream:

$$x_{\text{mid}} = x + \text{Attention}\bigl(\text{Norm}_1(x)\bigr), \qquad x_{\text{out}} = x_{\text{mid}} + \text{FFN}\bigl(\text{Norm}_2(x_{\text{mid}})\bigr)$$
Why normalize before each sublayer? Adding outputs across 32 to 80 layers would cause vector magnitudes to drift wildly. RMSNorm divides $x$ by its root-mean-square size $\text{RMS}(x) = \sqrt{\frac{1}{d}\sum_{i=1}^d x_i^2}$ so every sublayer sees well-scaled inputs while the unnormalized highway $+x$ stays clean.

Mental-math trace of RMSNorm on a 4D vector $x = [1, 1, 3, 5]$ (zero calculator needed):

1. Square each coordinate: $[1^2, 1^2, 3^2, 5^2] = [1, 1, 9, 25]$.
2. Average the squares across $d = 4$ dimensions: $\frac{1 + 1 + 9 + 25}{4} = \frac{36}{4} = \mathbf{9}$, so $\text{RMS}(x) = \sqrt{9} = \mathbf{3}$.
3. Divide $x = [1, 1, 3, 5]$ by $\text{RMS}(x) = 3$: $\text{RMSNorm}(x) = \mathbf{[\frac{1}{3},\; \frac{1}{3},\; 1,\; \frac{5}{3}]}$ (then multiply element-wise by learned scale weights $\gamma$).

3. The Fully Connected FFN (MLP): expand, gate, project back

Once Self-Attention has copied context from earlier tokens into the current token's residual vector $x_{\text{mid}}$, the token enters the Position-Wise Feed-Forward Network (FFN)—also called the MLP (Multi-Layer Perceptron) or fully connected sublayer.

"Position-wise" means the exact same two weight matrices $W_{\text{up}}$ and $W_{\text{down}}$ are applied to token 1's vector, token 2's vector, and token $N$'s vector completely independently—zero cross-token mixing happens here. If Attention is "gather relevant notes from your neighbors," the FFN is "sit alone at your desk and think about the notes you just gathered."

$$\text{FFN}(x) = \underbrace{\sigma\bigl(x\, W_{\text{up}} + b_1\bigr)}_{\text{hidden detectors } h \in \mathbb{R}^{d_{\text{ff}}}} W_{\text{down}} + b_2$$
Shape journey for 1 token: $(1 \times d_{\text{model}}) \xrightarrow{\times\, W_{\text{up}}\; (d_{\text{model}} \times d_{\text{ff}})} (1 \times d_{\text{ff}}) \xrightarrow{\sigma(\cdot)\text{ element-wise}} (1 \times d_{\text{ff}}) \xrightarrow{\times\, W_{\text{down}}\; (d_{\text{ff}} \times d_{\text{model}})} (1 \times d_{\text{model}})$.

Why expand to a wider dimension $d_{\text{ff}} \approx 4\,d_{\text{model}}$ and then squeeze back down to $d_{\text{model}}$? Think of the $d_{\text{ff}}$ intermediate neurons as a bank of key-value memory slots (Geva et al.):

  • Step 1 — Pattern Detection ($W_{\text{up}}$, columns are "keys"): Column $m$ of $W_{\text{up}}$ takes a dot product with the token vector $x$. It fires strongly when $x$ contains a specific combination of features (e.g., "token is 'in' AND attention just copied 'Paris' into $x$").
  • Step 2 — Non-Linear Gate (ReLU / GELU / SwiGLU): Zeroes out irrelevant detectors ($h_m \le 0 \to 0$) so unmatched memory slots stay silent instead of injecting noise. Without this non-linearity, $W_{\text{up}} W_{\text{down}}$ would collapse into a single linear matrix!
  • Step 3 — Value Write-Back ($W_{\text{down}}$, rows are "values"): Each active detector $h_m > 0$ multiplies row $m$ of $W_{\text{down}}$, adding a factual concept vector (e.g., "+capital-of-France / +French-geography") back into the residual stream.

Worked FFN trace with distinct numbers ($d_{\text{model}} = 2 \to d_{\text{ff}} = 3 \to d_{\text{model}} = 2$, zero biases):

Suppose after Attention + Norm, our token vector is $x = [2,\; -1]$. We pass $x$ through an FFN with ReLU activation $\sigma(u) = \max(0, u)$, expansion matrix $W_{\text{up}}$ ($2 \times 3$), and projection-back matrix $W_{\text{down}}$ ($3 \times 2$): $$W_{\text{up}} = \begin{bmatrix} 1 & -2 & 3 \\ 0 & 1 & 2 \end{bmatrix}, \qquad W_{\text{down}} = \begin{bmatrix} 2 & 1 \\ 5 & 6 \\ 0 & 3 \end{bmatrix}$$

1. Expand to $d_{\text{ff}} = 3$ pre-activations ($u = x W_{\text{up}}$):
• Neuron 1 (col 1 of $W_{\text{up}}$): $u_1 = (2)(1) + (-1)(0) = \mathbf{2}$.
• Neuron 2 (col 2 of $W_{\text{up}}$): $u_2 = (2)(-2) + (-1)(1) = -4 - 1 = \mathbf{-5}$.
• Neuron 3 (col 3 of $W_{\text{up}}$): $u_3 = (2)(3) + (-1)(2) = 6 - 2 = \mathbf{4}$.
So pre-activation vector is $u = [2,\; -5,\; 4]$.

2. Apply non-linear gate ($h = \text{ReLU}(u) = \max(0, u)$):
Neuron 2 is negative ($-5$), so ReLU shuts that gate completely to $0$: $$h = [\max(0, 2),\; \max(0, -5),\; \max(0, 4)] = \mathbf{[2,\; 0,\; 4]}$$

3. Project back to $d_{\text{model}} = 2$ ($\Delta x = h W_{\text{down}}$):
Because $h_2 = 0$, Row 2 of $W_{\text{down}}$ ($[5, 6]$) is completely ignored! Only Row 1 ($[2, 1]$) and Row 3 ($[0, 3]$) write into the output:
$$\Delta x = 2 \cdot \underbrace{[2, 1]}_{\text{row 1}} + 0 \cdot \underbrace{[5, 6]}_{\text{row 2}} + 4 \cdot \underbrace{[0, 3]}_{\text{row 3}} = [4, 2] + [0, 12] = \mathbf{[4,\; 14]}$$

4. Add back into the Residual Stream ($x_{\text{out}} = x + \Delta x$):
$$x_{\text{out}} = [2,\; -1] + [4,\; 14] = \mathbf{[6,\; 13]}$$

Modern twist: How SwiGLU (Llama, PaLM, Qwen) upgrades the FFN (Click to expand)

Classic Transformers use one up-projection $W_{\text{up}}$ followed by ReLU or GELU. Modern LLMs replace that single up-projection with a SwiGLU (Swish Gated Linear Unit) that runs two parallel up-projections—a gate matrix $W_{\text{gate}}$ and a value matrix $W_{\text{up}}$—and multiplies them element-wise ($\odot$):

$$\text{FFN}_{\text{SwiGLU}}(x) = \Bigl(\text{Swish}\bigl(x W_{\text{gate}}\bigr) \odot \bigl(x W_{\text{up}}\bigr)\Bigr) W_{\text{down}}$$

Because SwiGLU uses three matrices ($W_{\text{gate}}, W_{\text{up}}, W_{\text{down}}$) instead of two, models shrink intermediate width $d_{\text{ff}}$ from $4\,d_{\text{model}}$ to $\frac{8}{3}\,d_{\text{model}} \approx 2.67\,d_{\text{model}}$ so total FFN parameter count stays right at $3 \times \frac{8}{3} d_{\text{model}}^2 = 8\,d_{\text{model}}^2$.

4. Leaving the stream: the Unembedding Matrix ($W_U$) & Logits

After the token vector passes through all $L$ Transformer blocks (Attention $\to$ Add $\to$ FFN $\to$ Add, repeated $L$ times) and one final RMSNorm, we hold a single vector $x_{\text{final}} \in \mathbb{R}^{1 \times d_{\text{model}}}$ at the last sequence position.

How do we turn a $d_{\text{model}}$-dimensional vector (say, $4096$ numbers) into a prediction over $V = 100{,}000$ possible next words in the vocabulary? We multiply $x_{\text{final}}$ by the Unembedding Matrix $W_U \in \mathbb{R}^{d_{\text{model}} \times V}$ (often called the LM Head):

$$z = x_{\text{final}}\, W_U \in \mathbb{R}^{1 \times V}, \qquad p_j = \text{softmax}(z)_j = \frac{e^{z_j}}{\sum_{k=1}^{V} e^{z_k}}$$
Every column $u_j \in \mathbb{R}^{d_{\text{model}}}$ of $W_U$ is the target template vector for vocabulary token $j$. The $j$-th logit $z_j = x_{\text{final}} \cdot u_j$ is simply the dot-product similarity between the final residual stream and token $j$'s column!

Worked Unembedding trace ($d_{\text{model}} = 2$, vocabulary size $V = 4$, distinct numbers):

Suppose after the prompt "Paris is in", the final normalized residual vector at position "in" is $x_{\text{final}} = [3,\; 1]$. Our 4-token vocabulary is ["Paris", "is", "in", "France"], and the unembedding matrix $W_U$ ($2 \times 4$, one column per vocab word) is: $$W_U = \begin{bmatrix} 0 & -1 & 1 & 2 \\ 1 & 0 & -1 & 3 \end{bmatrix}$$ 1. Multiply $z = x_{\text{final}} W_U$ (one dot product per vocabulary column):
• Col 0 ("Paris", $[0, 1]^\top$): $z_0 = (3)(0) + (1)(1) = \mathbf{1}$.
• Col 1 ("is", $[-1, 0]^\top$): $z_1 = (3)(-1) + (1)(0) = \mathbf{-3}$.
• Col 2 ("in", $[1, -1]^\top$): $z_2 = (3)(1) + (1)(-1) = 3 - 1 = \mathbf{2}$.
• Col 3 ("France", $[2, 3]^\top$): $z_3 = (3)(2) + (1)(3) = 6 + 3 = \mathbf{9}$.

2. Read the logits $z = [1,\; -3,\; 2,\; 9]$:
Token 3 ("France") has the highest dot product ($z_3 = 9$) because its column $[2, 3]^\top$ aligns best with $x_{\text{final}} = [3, 1]$. Passing $z$ through softmax assigns over $99.8\%$ probability to "France".

Notice the symmetry between the start and end of the LLM: $W_E$ has shape $V \times d_{\text{model}}$ (maps token IDs into the residual stream), and $W_U$ has the exact transpose shape $d_{\text{model}} \times V$ (maps the residual stream back to token scores). Many LLMs use weight tying, setting $W_U = W_E^\top$ so the model reuses the exact same vocabulary vectors for reading and writing, saving $V \times d_{\text{model}}$ parameters.

A token enters the FFN with residual stream vector $x_{\text{mid}} = [1,\; 2]$. It passes through an FFN with ReLU activation where:
Step 1 (FFN Expansion & ReLU Gate): After multiplying by $W_{\text{up}}$ and applying ReLU, the 3 hidden FFN neurons are $h = [3,\; 0,\; 1]$ (neuron 2 was negative and gated to $0$).
Step 2 (FFN Down-Projection $\Delta x = h W_{\text{down}}$): The 3 rows of $W_{\text{down}}$ are Row 1 $= [1, 0]$, Row 2 $= [9, 9]$, and Row 3 $= [0, 2]$. Because $h_2 = 0$, Row 2 drops out, giving $\Delta x = 3\,[1, 0] + 0\,[9, 9] + 1\,[0, 2] = \mathbf{[3,\; 2]}$.
Step 3 (Residual Add): Adding $\Delta x$ back into the residual stream gives $x_{\text{final}} = x_{\text{mid}} + \Delta x = [1, 2] + [3, 2] = \mathbf{[4,\; 4]}$.

(2) Why does the FFN need a non-linear activation between $W_{\text{up}}$ and $W_{\text{down}}$? (3) What are the input, matrix shape, and output of the Unembedding Matrix $W_U$?

Canonical answer:
1. Attention vs. FFN: Self-attention routes information across different token positions, whereas the FFN processes each token's vector independently in isolation (expanding $d_{\text{model}} \to d_{\text{ff}} \to d_{\text{model}}$ to look up and inject learned factual/feature associations).
2. Why non-linearity is required: Without a non-linear gate (ReLU/GELU/SwiGLU), multiplying by $W_{\text{up}}$ and then $W_{\text{down}}$ would collapse into a single linear matrix $W_{\text{combined}} = W_{\text{up}} W_{\text{down}}$, unable to selectively switch memory slots on or off.
3. Unembedding Matrix $W_U$: Takes the final residual stream vector $x_{\text{final}} \in \mathbb{R}^{1 \times d_{\text{model}}}$, multiplies by $W_U \in \mathbb{R}^{d_{\text{model}} \times V}$ (one column per vocabulary word), and outputs $V$ unnormalized logits $z \in \mathbb{R}^{1 \times V}$ before softmax.

import torch
import torch.nn as nn
import torch.nn.functional as F

class RMSNorm(nn.Module):
    def __init__(self, d_model, eps=1e-6):
        super().__init__()
        self.weight = nn.Parameter(torch.ones(d_model))
        self.eps = eps

    def forward(self, x):
        # Normalize each token vector by its root-mean-square across d_model
        rms = torch.sqrt(x.pow(2).mean(dim=-1, keepdim=True) + self.eps)
        return (x / rms) * self.weight

class FeedForwardMLP(nn.Module):
    def __init__(self, d_model, d_ff):
        super().__init__()
        self.w_up = nn.Linear(d_model, d_ff, bias=False)
        self.w_down = nn.Linear(d_ff, d_model, bias=False)

    def forward(self, x):
        # Position-wise: expands d_model -> d_ff, gates, projects back -> d_model
        return self.w_down(F.gelu(self.w_up(x)))

class MiniTransformerLM(nn.Module):
    def __init__(self, vocab_size=32000, d_model=512, n_heads=8, d_ff=2048):
        super().__init__()
        self.w_e = nn.Embedding(vocab_size, d_model)          # W_E: [V, d_model]
        self.norm1 = RMSNorm(d_model)
        self.attn = nn.MultiheadAttention(d_model, n_heads, batch_first=True)
        self.norm2 = RMSNorm(d_model)
        self.ffn = FeedForwardMLP(d_model, d_ff)              # FFN: [d_model -> d_ff -> d_model]
        self.final_norm = RMSNorm(d_model)
        self.w_u = nn.Linear(d_model, vocab_size, bias=False) # W_U: [d_model, V]

    def forward(self, token_ids):
        # 1. Enter residual stream via embedding lookup
        x = self.w_e(token_ids)                               # [B, N, d_model]
        # 2. Pre-Norm + Attention + Residual Add
        h_norm = self.norm1(x)
        attn_out, _ = self.attn(h_norm, h_norm, h_norm, need_weights=False)
        x = x + attn_out
        # 3. Pre-Norm + Fully Connected FFN + Residual Add
        x = x + self.ffn(self.norm2(x))
        # 4. Final Norm + Unembedding projection to vocabulary logits
        logits = self.w_u(self.final_norm(x))                 # [B, N, V]
        return logits
